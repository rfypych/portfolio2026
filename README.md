- **Vite** (Lightning-fast build tool)

- **Lenis** (Smooth scroll experience)
- **Firebase** (Backend & Analytics)

## 🚀 Development Setup

To run this project locally:

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

## 🔄 Domain Management Tool

This repository includes a custom, automated script to quickly update the active domain across all SEO configurations (Canonical tags, Open Graph, Twitter Cards, Sitemap, robots.txt, and Vite config). 

Whenever you migrate or switch to a new domain name, simply run:

```bash
npm run change-domain <old-domain> <new-domain>
```

*(Alternatively, you can also use `npm run set-domain <old-domain> <new-domain>`)*

**Example usage:**
```bash
npm run change-domain rfiklz.vercel.app rofikul.vercel.app
```

The script will automatically detect and replace the domain in all necessary files. After it finishes, simply verify the changes and commit them to Git.
